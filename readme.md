1.根据main11.py 和 embedding.py 创建一个main12.py
2.在gradio中可以上传doc和txt形式的文件，然后可以进行问答
3上传的文件分别利用embedding.py模块中的功能进行向量化，然后存储在faiss中，然后进行问答
4.问答的方式是根据上传的文件进行问答，然后返回答案，只能根据上传的文件进行问答，不能根据其他文件进行问答，可以在列表里进行选择
5.上传的文件可以进行删除，删除的文件会从faiss中删除，然后从数据库中删除
6.上传的文件类型embedding之后是类似于刑法_embeddings.npy的文件，在embedding之前可以进行命名，然后进行上传，上传的文件会进行embedding，然后存储在faiss中，然后进行问答
